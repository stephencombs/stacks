# Design frames

Renders of the Claude Design canvas (https://claude.ai/artifact/TuT3hbPr6ZCyWZcBX4Rjx5), light and dark.
`android/` is 1080 px wide (Pixel 9), `ios/` 1179 px wide. See `docs/design/frames.md` on `main`
for which screen each frame covers and how to compare. The canvas wins if these are stale.
